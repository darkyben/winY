Unicode character names, Unicode 16.0.0, from Python unicodedata (Unicode Character Database).
Includes named punctuation, symbols, marks, numbers, spaces, and Latin/Greek/Cyrillic letters.
https://www.unicode.org/ucd/
Alt codes: legacy DOS control symbols and Windows-1252; leading zero is significant.
The original reference https://gist.github.com/jpassaro/bf400b0410810a071a7fb3509ef6c2c3 contains Vim digraphs, not Windows Alt codes.
